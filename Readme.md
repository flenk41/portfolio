# Portfolio

Консольная программа на TypeScript: загружает портфель акций из JSON-файла, проверяет данные и считает стоимость. Первый учебный проект в рамках изучения TypeScript.

## Что умеет

- читает портфель из файла `portfolio.json`
- проверяет каждый актив: тикер — строка, количество и цена — числа
- если данные битые, останавливается и показывает, какой элемент сломан и что в нём лежит
- считает стоимость каждой позиции и итог портфеля

## Как запустить

Нужен установленный Node.js.

```
npm install
npx tsc
node dist/load.js
```

## Пример

Файл `portfolio.json`:

```json
[
    {"ticker":"SBER", "amount":10, "price":28},
    {"ticker":"APLL", "amount":120, "price":590},
    {"ticker":"ALFA", "amount":1, "price":125}
]
```

Вывод:

```
Портфель загружен: 3
SBER:280
APLL:70800
ALFA:125
Итого: 71205
```

Если в файле ошибка, например `"amount":"1"` в кавычках, программа остановится:

```
Error: Элемент 3: неверный формат актива: {"ticker":"ALFA","amount":"1","price":125}
```

## Что внутри

- **TypeScript** в строгом режиме и **Node.js**
- `src/asset.ts` — тип `Asset` и проверка `isAsset`
- `src/load.ts` — чтение файла, проверка, подсчёт и вывод
